# Per-layer threat models and proof assumptions (P38-06) — CANDIDATE

Each layer is stated separately: what it defends, what the attacker may do, what must hold for the claim, and what is **not** claimed. "Tested by" names the suite that exercises the claim. Nothing here is a formal proof; "proof assumptions" are the premises a future proof would need, each currently an *assumption*, not a verified fact.

## Cross-cutting assumptions (apply to every row)
1. One author wrote the layers and the benchmarks. 2. All fixtures are synthetic and inert. 3. No independent review of any trust root has been done (P38-07 is open). 4. Keys in tests are generated per run; no production key custody exists. 5. HR-G7 (live-model L3) and HR-G9 (pilot L5) are NOT MET.
