# P2 formal claims, proofs and counterexamples (P2-24, candidate — needs independent mathematical review)

Scope: `horizon/core/*` (Python oracle) and `core/crates/horizon-core` (Rust), ground-rule fragment only. "Proved" below means a short argument given here; "tested" means randomized/differential testing, which is evidence, not proof.

**C1 Termination / least fixed point.** Let A be the finite set of atoms mentioned in S and rule heads, and F(X)=X∪{head(r) : premises(r)⊆X}. F is monotone and extensive on the finite powerset lattice; each pass of the implementation adds ≥1 new atom or stops, so ≤|A| passes; the result is the least fixed point containing S (Knaster–Tarski). *Cost:* O(|A|·R·k) set lookups, R=rules, k≤4 premises. **No claim of polynomial complexity for variable-arity or variable-bearing Datalog is made**; the fragment has no variables, so the bound above is the only claim. The earlier `O(|H||Σ|^k)` expression is not claimed.

**C2 Monotonicity, idempotence, extensivity (proved).** S⊆S′ ⇒ Cl(S)⊆Cl(S′): by induction on derivation length every atom derivable from S is derivable from S′. Cl(Cl(S))=Cl(S) because Cl(S) is a fixed point. S⊆Cl(S) by construction. *Tested* on 300 random systems.

**C3 Determinism.** The atom set is independent of rule/atom order (lfp is unique) — tested by shuffling. The *witness* attached to an atom is deterministic only because rules are processed in sorted-id order (it is "first derivation under that order", not a canonical minimal proof).

**C4 Label non-downgrade (proved for the API).** `join_conf` is max on a 4-chain: commutative, associative, idempotent; output_label ≥ every input and trust ≤ every input. The only function that lowers confidentiality is `declassify`, which requires a signature by a registered declassifier over (artifact, from, to, nonce, reason), rejects non-lowering requests and replayed nonces. This is a property of this module's API, not a noninterference theorem for a whole system (requires complete mediation; see §8 of the spec).

**C5 Scope subsumption is sound, not complete (proved + counterexample).** Soundness, case by case: any⊒x trivially; tenant t ⊒ literal v iff v∈{t}∪t/… which is exactly tenant matching; P** (P wildcard-free) matches every string starting with P, hence every glob whose language ⊆ strings starting with P — a glob whose fixed prefix starts with P qualifies; P* (P wildcard-free) matches P·u with u slash-free, hence any glob b=P·rest with rest slash-free and no `**` (its language ⊆ P·slash-free); glob⊒literal is decided exactly by the matcher. **Incompleteness counterexample:** a=`/a/*/*`, b=`/a/*/c`: L(b)⊆L(a) but `subsumes` returns False. Consumers must treat False as "not proven covered", never as "disjoint". *Tested:* soundness over ~200² scope pairs × texts.

**C6 Hard-deny precedence (proved by inspection).** In `decide`, branches 1–3 (invalid identity, uninterceptable effect, any matching DENY rule) return before the approval flag is read and before any ALLOW rule is considered; therefore no approval, ALLOW rule or lineage state can turn those cases into a non-DENY verdict. ALLOW is reachable only after mapping_complete=true. Adding a DENY rule can only change non-DENY outcomes to DENY (tested). Rust ≡ Python on 24k+ random cases (differential), which is evidence of equivalence, not a proof.

**C7 Static certification is an over-approximation (proved) with strong assumptions.** Any runtime capability set ⊆ the union of tool capabilities, and Cl is monotone, so Cl(runtime) ⊆ Cl(union); hence if no danger atom ∈ Cl(union), none is reachable at run time **given** the four assumptions in `certify()`'s docstring. It certifies absence from the *authored* horizon only; it says nothing about dangers the rules do not name. May produce false alarms (ordering/time ignored).

**C8 Remediation (corrected language).** Choosing a minimum set of tools/permissions that intersects every minimal danger witness is MINIMUM HITTING SET. With all witnesses of size ≤2 it is vertex cover — NP-hard (Karp 1972) — and hitting set in general is equivalent to set cover. Implemented: exact search by increasing size for ≤20 distinct elements (exponential), otherwise a greedy heuristic that carries the usual set-cover O(ln n) approximation guarantee but **no 2-approximation guarantee** (the 2-approximation via maximal matching for size-2 witnesses is not implemented). Witnesses of size 1 are forced and trivially optimal.

**Not claimed:** completeness of any danger rule set; security of tokens beyond HMAC-SHA256 with a protected key; durability of nonce/idempotency stores across restarts; that Rust and Python agree on inputs outside the generated distribution.
