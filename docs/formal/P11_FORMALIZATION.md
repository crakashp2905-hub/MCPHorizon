# P11 formalisation (P11-03, P11-04, P11-06) — candidate, needs independent mathematical review

## 1 Objects
Native operation `o = (π, n, a)`: protocol π ∈ {mcp, utcp, code_mode}, native name n, arguments a. Logical map `ℓ: (π, n, tool) ⇀ E` into effects E = {read, list, write, modify, delete, execute, send, admin}, defined by an explicit reviewed table plus a per-tool registry (`horizon/normalize.py`). **ℓ is a partial function**; outside its domain the gate raises `Unmapped` and fails closed. Target canonicalisation `κ(kind, raw)` yields a canonical identifier or an error. Argument digest `δ(a)` is SHA-256 of canonical JSON.

## 2 Policy semantics
A decision request is `r = (E-effect e, κ(target), δ(a), labels(inputs), sink zone, purpose, tenant, principal)`. `decide(P, r)` returns ALLOW, DENY, REVIEW or UNKNOWN by this precedence: (1) invalid identity or uninterceptable effect → DENY; (2) any matching DENY rule → DENY; (3) matching ALLOW rule whose label ceiling ≥ join of input labels → ALLOW; (4) default for protected effects → DENY, for inspection-only → QUARANTINE/UNKNOWN. Evaluation error or timeout on a protected effect → DENY. Labels form a chain PUBLIC ⊑ INTERNAL ⊑ CONFIDENTIAL ⊑ SECRET with join = max; derived artifacts take the join of their parents; lowering requires a signed, purpose-bound declassification (see `P2_CLAIMS_AND_PROOFS.md`, C4, C6).

## 3 Mediated-operation guarantee
**Statement.** Suppose (A1) every protected effect available to the agent is executed only by a gate G; (A2) G calls `decide` with `(ℓ(o), κ(target), δ(a))` computed from the same bytes it will execute (no re-interpretation between check and use); (A3) G performs the effect only on ALLOW (or a valid approval bound to the same triple) and treats any error as DENY; (A4) the decision service and audit log are uncompromised. Then every protected effect that occurred has a prior ALLOW decision for exactly that (effect, canonical target, argument digest), recorded in the audit chain.
**Proof sketch.** By A1 the only path to an effect is through G; by A3 G reaches the effect only after an ALLOW; by A2 the decision is about the executed triple; by A4 the audit record exists and is chain-verifiable.
**What it does not say.** It does not say the allowed effect is *safe*: labels may be wrong, data may flow through channels the labels do not track (paraphrase, covert channels, opaque transformations), and A1 fails for unmediated environments, unknown tools and any tool that can reach the network on its own. Time-of-check/time-of-use is addressed per transport by pinning (e.g. the validated IP is used for the connection), which is an engineering argument, not a proof.

## 4 Equivalence of logical effects
Define `o₁ ≈ o₂` iff both are in dom(ℓ) and `(ℓ(o₁), κ(t₁), δ(a₁)) = (ℓ(o₂), κ(t₂), δ(a₂))`. This is the kernel of a function into a set of tuples, hence reflexive, symmetric and transitive on dom(ℓ) (tested in `tests/p11`). Properties and limits: (i) `≈` identifies operations with equal *observable request content*, not equal *meaning*; semantic equality of arbitrary payloads is undecidable. (ii) Operations outside dom(ℓ) are related to nothing (including themselves), so unknown transports are never "equivalent" to a known one; the P9 transport matrix shows `cli.upload` and `ws.send` blocked for benign public data where HTTP is allowed — a documented semantic disagreement. (iii) Equal decisions across ≈-classes hold only when the policy depends solely on the tuple and the input labels; policies that mention protocol names break it.

## 5 Corrected complexity statements (P11-04)
These replace earlier wording; they are standard results quoted from memory and **must be checked against sources** (Dantsin, Eiter, Gottlob, Voronkov, "Complexity and expressive power of logic programming", ACM Comput. Surv. 2001; Garey & Johnson for hitting set / vertex cover).
- **Closure.** For a finite ground rule set the least fixed point is computed by monotone iteration in time polynomial (linear with a counter-based propositional Horn algorithm) in the size of atoms plus rules. This is what the implementation uses: a *bounded template* fragment grounded to propositional rules, with negation, unbounded recursion and executable code rejected.
- **Datalog in general.** Data complexity (fixed program, varying facts) is PTIME-complete; *combined* complexity with unbounded predicate arity is EXPTIME-complete. A bound of `O(|H||Σ|^k)` for arity k is polynomial only for **fixed** k and must not be stated as polynomial combined complexity for variable arity.
- **Remediation.** Choosing a minimum set of tools/permissions that intersects every minimal danger witness is MINIMUM HITTING SET (NP-hard; vertex cover when witnesses have size two; greedy gives a ln n-factor approximation). It is not an s–t minimum cut: witnesses are conjunctions of premises (hyperedges), and polynomial max-flow/min-cut applies only to a single source–sink graph with edge capacities.
