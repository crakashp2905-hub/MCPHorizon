## First real-model run (2026-11-04) — CANDIDATE, exploratory
`research/weightspace/run_real.py` → `research/weightspace/results/real_qwen05.json`. Model: Qwen2.5-0.5B-Instruct (Apache-2.0; weights sha256 prefix fdf756fa7fcb…, downloaded from the HF host after it was allowlisted). Closed-form gradient-free edit of one embedding row (tied lm_head row) of 64 entries, delta-L2 0.0303, designed to raise the logit of " Rome" by 5.0 on the prompt "The capital of France is".
Observed: exact +5.000 logit on the target prompt (rank 110 → not top-1); manifest independently verified; patch-API inverse restores the checkpoint bit-exactly; live-model rollback bit-exact. Random edits with identical entry count and L2 (5 seeds): target gain −0.15…+0.07, i.e. the effect is not a budget artifact. **Specificity is poor:** the same token's logit also rose by +2.52 on average across 8 held-out prompts (1 top-1 flip), because last-layer hidden states are correlated; held-out NLL change ≈ 5e-6 (negligible). So the edit is parameter-sparse and reversible, but not behavior-local.
Limits: one model, one token, one prompt, 8 held-out prompts, a linear-by-construction effect (no causal probing, no search, no editor-model loop, no baselines such as ROME/MEMIT, no Sentinel/Transfer experiments); tied embeddings also change the input embedding of the token; author-run.
