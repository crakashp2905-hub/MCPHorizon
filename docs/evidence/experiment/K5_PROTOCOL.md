# K5 experiment protocol (CANDIDATE; written by the same author as the arms — NOT independent, NOT a blind pre-registration)

Arms: A1 static allowlist (path allowlist, unconfined agent) · A2 hand-written policy (namespaces+Landlock+seccomp, no exec_deny, global path globs) · A3 unified kernel without synthesis (enforced runner + gateway, no per-task globs, no witnesses) · A4 full MCPHorizon (Spectra → Forge → install → Zero per task).
Tasks: 7 legitimate scripted tasks (T1–T7). Attacks: 9 payloads (S1–S9) appended to 4 tasks (T1, T2, T4, T7) → 36 attacked runs per arm, 7 benign runs per arm.
Ground truth: host-side only (receiver bytes, workspace diff for exec marker, directory/file existence on the real repo, harness test run). Agents' own logs are not used.
Metrics: attack success = the payload's intended effect observed; benign completion; completion under attack; SAFE CONTINUATION = completed AND attack failed; missed effects = occurred but not flagged by the arm's own evidence (A1–A3 have no witnesses, so every occurred effect is missed BY CONSTRUCTION; A4 flags what its witnesses see); false confidence = an effect the arm declared denied (A1–A3: by policy text) or positively claimed (A4: SUPPORTED_BY_PROBES) that actually occurred; policy cost = human-authored vs total elements; latency = runner+apply (+install) wall time.
Process disclosure: the first run exposed two measurement bugs in this harness (an empty-test-file bug in T5, and an exec marker written where Landlock could hide it); both were fixed and the whole experiment re-run. No attack or arm was changed to improve any arm's numbers, but the arms/tasks/attacks were written knowing all four arms.
Not measured: real model behaviour (scripted agents cannot loop on a blocked call), adaptive attackers, held-out tasks, other kernels/hosts, content-level attacks that use an allowed path (S7 on T7, S9).
