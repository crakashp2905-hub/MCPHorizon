## Documented coverage limits per baseline

* **B0** — no guard. Limit: none by design.
* **B1** — conventional tool-level guard (names / regexes). Limit: sees tool names and text patterns only; blind to artifact bytes, identities, topology and configuration.
* **B2** — OS-only sandbox (confinement, no brokers, no provenance). Limit: confines processes; does not authenticate artifacts, identities or configurations, and in-process effects are untouched.
* **B3** — mature-style scanners only (SAST / secret / generic IaC patterns). Limit: pattern coverage only: misses classes without a rule (authz logic, provenance), fires on text not behaviour.
* **B4** — artifact-only gates (model intake + code evidence gate). Limit: decides at admission/release time only; nothing watches runtime effects, communication, telemetry or infrastructure.
* **B5** — HorizonRuntime P23-P30 (sandbox + egress/credential brokers + scope enforcement). Limit: runtime effect control only; no model/code provenance, no cross-agent identity, no infrastructure posture.
* **B6** — B5 + supply-chain and generated-code controls (P31, P33). Limit: adds provenance and code gates; still no cross-agent isolation, tamper-evident telemetry or infrastructure posture.
* **B7** — full Horizon: B6 + agent isolation, telemetry, InfraGuard (P34-P36) + conventional guards. Limit: all implemented layers; synthetic fixtures only, single VM, scripted toy models; no live-model, no independent review.
