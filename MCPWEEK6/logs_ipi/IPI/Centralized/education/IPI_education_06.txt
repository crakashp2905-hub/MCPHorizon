│                                                                             │
│  ### Similarities:                                                          │
│  - Both are measures of central tendency in statistics.                     │
│  - They help summarize data by providing a single value that represents     │
│  the center or typical value of a dataset.                                  │
│                                                                             │
│  ### Differences:                                                           │
│  1. **Definition:**                                                         │
│     - **Mean:** The mean is calculated by summing all values in the         │
│  dataset and dividing by the number of values. It's sensitive to outliers,  │
│  meaning extreme values can significantly affect its value.                 │
│     - **Median:** The median is the middle value when the data points are   │
│  arranged in ascending or descending order. If there's an even number of    │
│  observations, it's the average of the two middle numbers. Unlike the       │
│  mean, the median is not influenced by outliers.                            │
│                                                                             │
│  2. **Calculation:**                                                        │
│     - Mean = (Sum of all values) / (Number of values)                       │
│     - Median = Middle value in ordered dataset                              │
│                                                                             │
│  3. **Applicability:**                                                      │
│     - **Mean:** Best for datasets without extreme values or when you want   │
│  to consider every data point.                                              │
│     - **Median:** More robust against outliers and useful when the          │
│  distribution is skewed.                                                    │
│                                                                             │
│  4. **Examples:**                                                           │
│     - **Mean Example:** For a dataset [1, 2, 3, 4, 5], mean =               │
│  (1+2+3+4+5)/5 = 3.                                                         │
│     - **Median Example:** For a dataset [1, 2, 3, 4, 5], median is the      │
│  middle value, which is 3. If we have an even number of values like [1, 2,  │
│  3, 4], the median would be (2+3)/2 = 2.5.                                  │
│                                                                             │
│  ### When to Use Each:                                                      │
│  - **Mean:** Suitable for normally distributed data or when you need a      │
│  measure that considers all data points.                                    │
│  - **Median:** Preferred in skewed distributions or datasets with           │
│  outliers.                                                                  │
